# Joe Nikson: Portfolio

A clean, mobile-first portfolio built with plain HTML, CSS and JavaScript. No frameworks, no build step.

**[Live site](https://simpleportfolioim.netlify.app)**

## Sections

- **Home:** short introduction and a contact button
- **About:** who I am, education, and career objective
- **Skills:** HTML, CSS, JavaScript, responsive design, Git and GitHub, basic React
- **Contact:** email, GitHub and LinkedIn

## Highlights

- Responsive layout with a collapsible mobile menu
- Scroll-triggered fade-in animations
- Accessible markup: semantic landmarks, ARIA labels on the nav toggle, inline SVG icons
- Inter typeface via Google Fonts

## Tech stack

- HTML5, CSS3, vanilla JavaScript
- Deployed on Netlify

## Run locally

```bash
git clone https://github.com/Joenikson/simple_portfolio.git
cd simple_portfolio
```

Open `index.html` in a browser, or run `npx serve .`.

## Project structure

```
simple_portfolio
├── public/      favicon and static assets
├── index.html   page markup
├── style.css    styles
└── script.js    nav toggle, scroll animations, footer year
```
